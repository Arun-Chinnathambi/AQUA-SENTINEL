# Experimental setup for the revised manuscript

## Data protocol

Refined Deep-SAR is used for pixel-level segmentation training, validation and testing. Because the public release is organized into Sentinel-1 and PALSAR sample groups rather than documented co-registered pairs, the main experiment should be single-stream SAR segmentation. Split at source/sample identity level before augmentation or tiling; do not permit augmented variants of the same parent sample to cross partitions. Use seed 42. Report the exact counts generated by the final manifest as Table III rather than inventing counts.

DARTIS is held out from training and used as an external object-level look-alike benchmark. It should not be used to claim pixel-level external segmentation validation. Because DARTIS contains bounding-box/object annotations rather than segmentation masks, report detection precision/recall/F1 or AP and false-positive rates on no-oil subsets, not Dice/IoU.

## Training

Adam, lr=1e-4, batch=4, 35 epochs, gradient norm clipping=1.0, ReduceLROnPlateau factor=0.5 patience=3. Epochs 0-9: encoders frozen; epochs 10-34: all layers fine-tuned. Seed 42 and deterministic cuDNN.
